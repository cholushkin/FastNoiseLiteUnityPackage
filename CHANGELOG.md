# Changelog

All notable changes to this package are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.1.1] - 2026-10-30

### Added
- Initial UPM release of FastNoiseLite 1.1.1 as a standalone, Git-installable Unity package.
- `Runtime/FastNoiseLite.cs` — upstream FastNoiseLite 1.1.1, including the Terraxel convenience
  constructor `FastNoiseLite(seed, frequency, octaves, lacunarity, gain)`.
- `Runtime/QCat.FastNoiseLite.asmdef` runtime assembly definition.
- Optional "Noise Examples" sample with 12 example scenes/scripts, shared visualization
  helpers, EditMode tests, and its own documentation.
